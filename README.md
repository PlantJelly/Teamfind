# Teamfind — 팀 매칭 플랫폼

Spring MVC + MyBatis + Oracle DB 기반의 팀원 모집·지원 플랫폼입니다.  
일반 로그인, 카카오 로그인, 얼굴 인식 로그인을 하나의 서비스에서 제공하고, 팀 모집부터 지원 승인·거절과 알림까지 구현했습니다.

- 기간: 2026.06.01 ~ 2026.07.01
- 인원: 1명
- Backend: Java 17, Spring MVC, MyBatis, Oracle DB
- View: JSP
- Face Recognition: Python, FastAPI, InsightFace(ArcFace)

---

## 주요 기능

- 회원가입 및 세션 기반 로그인
- 카카오 OAuth 로그인
- 얼굴 등록 및 얼굴 인식 로그인
- 팀 모집글 등록·수정·삭제
- 팀 지원 및 지원 내역 관리
- 모집자가 지원자를 승인·거절하는 흐름
- 지원 결과 알림
- 게시판 및 댓글

## 얼굴 인식 로그인

초기에는 MediaPipe를 사용해 얼굴 인증을 구현하려 했지만, 얼굴의 랜드마크를 검출하는 기능만으로는 사용자를 식별하기 어렵다는 한계를 확인했습니다.

이후 **InsightFace의 ArcFace 임베딩 방식**으로 변경했습니다.

Spring 애플리케이션에서 얼굴 이미지를 직접 처리하지 않고 Python/FastAPI 서버를 별도로 분리했으며, REST API를 통해 얼굴 등록과 인식 결과를 주고받도록 구성했습니다.

```text
Browser
   │
   ▼
Spring MVC
   │  REST / multipart
   ▼
FastAPI
   │
   ▼
InsightFace (ArcFace)
```

얼굴 이미지에서 512차원 임베딩을 추출하고 저장된 임베딩과 코사인 유사도를 비교해 사용자를 식별합니다. 등록 시에는 다른 계정에 이미 등록된 얼굴인지도 확인합니다.

## 인증 구조

서비스에서는 세 가지 로그인 방식을 지원합니다.

- **일반 로그인** — Oracle DB의 회원 정보와 세션을 이용한 인증
- **카카오 로그인** — OAuth 인증 후 회원 정보를 조회하고 세션 생성
- **얼굴 로그인** — FastAPI 얼굴 인식 서버에서 회원 ID를 반환받아 세션 생성

서로 다른 인증 방식을 최종적으로 동일한 회원 세션으로 연결하도록 구성했습니다.

## 팀 매칭 흐름

팀 모집자는 모집글을 작성하고 지원자를 확인할 수 있으며, 지원자는 원하는 팀에 지원할 수 있습니다.

```text
팀 모집글 작성
    ↓
지원자 신청
    ↓
모집자 지원 목록 확인
    ↓
승인 / 거절
    ↓
지원 결과 알림
```

지원 상태는 `PENDING`에서 시작하며 모집자가 승인 또는 거절할 수 있도록 구현했습니다.
